# TxnLang
> 一种 “面向资金流的声明式记账语言”

Design by diff4x

---
## 设计理念
- 流即真相 (Flow is Truth)
- 文本即数据库 (Plain Text as Database)
- 多主体共享 (Multi-Entity Shared)

## 约定
- 每一行代表一条独立指令，指令分为：流水行、月份行、年份行 和 注释行
  - 自顶向下查找归属
    - 流水行归属其向下遇到的最近月份行
    - 月份行归属其向下遇到的最近年份行
    - 最新流水永远插在文件最顶部
- 信用 `0` 本位，账单记负，溢缴记正
- 三类流动：收入、支出、中转, 其中支出必带分类
- 退款即冲销，退款不记为“收入”，而是“负向支出”，避免收支虚高
  - 负数仅用于初始负债和退款冲销 
- 需要记录确切日期时, 在金额后面附带`d`具体日
- 流水备注结尾空格起, 行注释#起

## BNF
```text
<file>        ::= { <line> | <comment> | <empty> }+
<line>        ::= <year_line> | <month_line> | <flow_line>
<year_line>   ::= <4_digit_number>
<month_line>  ::= <1_to_2_digit_number>
<flow_line>   ::= <src> <dst> [<cat>] <amount> [<date>] [<note>]
<src/dst>     ::= <account> | "i" | "e"
<account>     ::= "a".."m" | "n".."z"    /* 账户划分 */
<cat>         ::= "s" | "z" | "j" | "w" | "y" | "q" | "r" | "f"
<amount>      ::= ["-"] <number>
<date>        ::= "d" <1_to_2_digit_number>
<note>        ::= " " <text>
<comment>     ::= "#" <text>
```
## 帐户定义
```text

const ACCOUNTS = { // 源头
    // ♂️ 我的账户
    a: '现金(♂️)',   // a~m 帐户代码对 ♂️ 开放, ♂️ 启用了其中的 a, b, c, 并设置了别名, "现金(♂️) " 实际指代帐户 a
    b: '储蓄(♂️)',
    c: '信用(♂️)',
    // 追加, a~m
    
    // ♀️ 队友账户
    n: '现金(♀️)',   // n~z 帐户代码对 ♀️️ 开放, ♀️️ 启用了其中的 n, o, p, 并设置了别名,  "现金(♀️️) " 实际指代帐户 n
    o: '储蓄(♀️)',
    p: '信用(♀️)'
    // 追加, n~z
};

const DST_MAP = {   // 流向
    i: '收入',
    e: '支出',
    ...ACCOUNTS
};

const CAT_MAP = {   // 流向支出必须带上支出类别代码
    s: '食物',
    z: '住所',
    w: '网络',
    j: '交通',
    y: '医疗',
    r: '日化',
    f: '服饰',
    q: '其它'
};
```
